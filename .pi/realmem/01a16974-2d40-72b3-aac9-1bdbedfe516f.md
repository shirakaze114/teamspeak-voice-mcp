- crates.io 上 tsclientlib 0.2.0（2021）已过时；GitHub ReSpeak/tsclientlib master（2026-07，rev ee3bc6f）仍维护，要用 git 依赖。仓库有子模块 `utils/tsproto-structs/declarations`（tsdeclarations），本地克隆后需 `git submodule update --init`（cargo git 依赖会自动拉子模块）。参考克隆在 `~/Documents/workspace/_ref/tsclientlib`。
- 收音：`con.events()` 产出 `StreamItem::Audio(InAudioBuf)`，`packet.data().data()` 为 `AudioData::S2C{from,..}` / `S2CWhisper{from,..}`，`from` 即发言者 ClientId。
- `tsclientlib::audio::AudioHandler<Id>`：`handle_packet(id, pkt)` 入队（含抖动缓冲、乱序、FEC），`fill_buffer_with_proc(buf, |id, samples| ..)` 每次拉取时回调每个用户混音前的样本（48 kHz 立体声交错 f32），返回值是停止说话的用户列表 → 可直接用于按人分轨。
- 发音：`con.send_audio(OutAudio::new(&AudioData::C2S{id:0, codec: CodecType::OpusVoice, data}))`，20 ms/960 样本 48 kHz；发空 data 表示结束。
- 文字：`con.get_state()?.send_message(MessageTarget::Channel, text).send(&mut con)?`（需 `use tsclientlib::prelude::*` 的 OutCommandExt）。
- 状态：`get_state()?.clients`（HashMap<ClientId, Client>，含 name/uid/channel/database_id），`own_client`。
- 超时和服务器重启时会自动重连（产出 `StreamItem::DisconnectedTemporarily`），被踢/封禁时不会重连。
- `Identity::create()` 生成新身份（level 8）；Identity 实现了 serde，可以持久化。
