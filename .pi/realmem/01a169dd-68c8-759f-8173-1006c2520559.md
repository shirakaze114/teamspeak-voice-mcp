- VAD 使用 crates.io `silero` 0.7（捆绑 ONNX 模型，`Session::bundled()`，`SpeechSegmenterExt` 驱动每人一个 `StreamState`），替代手写 VAD；它内部使用 `zuoer` 分段器，16 kHz 默认帧 512 samples。
- TTS 使用 `async-openai` 0.42（`OpenAIConfig::with_api_base` + `audio().speech().create`），配置 `[tts] kind="openai"`、`base_url`（到 `/v1`）、`model`、`voice`；`format="pcm"` 时按配置采样率解释 s16le。
- 音频文件/响应解码用 `symphonia` 0.6（wav/pcm/mp3/flac/ogg/vorbis features），重采样仍用 `rubato`，Opus 用 `audiopus`。
- ASR 没有采用 `async-dashscope`：其接口不覆盖本项目 qwen-audio ASR 的 HTTP/WebSocket 协议，`src/asr.rs` 自己实现两个很小的客户端。HTTP sample_rate 按官方 API 是字符串 `"16000"`，返回全文在 `output.text`。
- `src/asr.rs` 的单元测试用本地模拟 HTTP/WebSocket 服务，不访问外网；已验证请求格式、100ms/3200字节 PCM 分帧、finish-task 和最终结果。
